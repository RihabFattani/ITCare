# ITCare - Back-end (Spring Boot 3.2.2)

Projet de challenge FullStack 2026 - groupe `com.sip`, artefact `itcare`.

## Demarrage
1. Demarrer **MySQL** dans XAMPP (root, mot de passe vide).
2. Lancer `ItcareApplication` (STS : Run As > Spring Boot App) ou `./mvnw spring-boot:run`.
3. API : http://localhost:8081/api
